# Monochrome Impact Design System

## Brand & Style
Monochrome Impact adopts a bold, minimalist, high-contrast aesthetic. It leverages a strong monochromatic color scheme coupled with distinct, striking typography (Anton for headlines, Poiret One for body, and Bebas Neue for labels) to create a clean, modern, and uncompromisingly direct visual identity.

## Colors
The color palette is strictly monochrome, utilizing uniform neutral gray tones (`#777777`) across primary, secondary, tertiary, and neutral roles to emphasize form, typography, and structure.

## Typography
- **Headlines:** Anton
- **Body:** Poiret One
- **Labels:** Bebas Neue

## Layout & Spacing
A structured, clean layout philosophy using a consistent spacing scale with standard gutters (`1.5rem`) and margins (`2rem`).

## Elevation & Depth
Elevation is achieved primarily through low-contrast outlines and tonal layering, avoiding heavy shadows in favor of structural clarity.

## Shapes
Roundedness level `2` (Rounded) is applied to all UI elements, introducing moderate corner radii (`0.5rem` base).

## Components
Components are styled with clear boundaries, distinct typographic labels (Bebas Neue), and readable body text (Poiret One).
